Role tokens — hex by theme

Every control part draws from this small set of semantic tokens. Swatches and hex are read live from the active theme, so they always match what renders above.

Part & state → token

What each part uses in each state. Controls split into two families: text (editable — focus to a well) and pick (selectable — focus reverses video).

partfamilystatefilltext

Theme resource keys

The dictionary a WPF theme would declare — base/shared brushes first, then per-control in selector precedence; states within each control in setter/trigger order (Normal → Hover → Focus → Pressed/Active → Disabled). Values resolve live from the active theme.
