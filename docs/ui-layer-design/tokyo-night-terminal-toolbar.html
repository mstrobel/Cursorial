tokyo-night — standalone toolbar — 96×40
Standalone toolbar with discrete overflow: one row of bar controls — buttons, a toggle group, split & popup buttons, and gallery comboboxes — that pockets its tail into a » popup when the row runs out of cells. This is the cell-grid answer to the ribbon’s fluid variant resizing: no interpolation, just a computed decision about which controls fit.

The bar controls in action. A split button has two hit zones — the left runs the default action, the right arrow opens the menu. With no separator cell, the arrow lives in its own tinted accent cell so it reads as independently clickable; hovering each zone highlights only that zone. A popup button (one target) shows a bare caret and drops a standard menu with accelerators. The gallery combobox drops font choices as preview rows (the selected one ticked). And the Color split button drops a gallery grid — a whole-cell swatch palette, the active colour ringed. These are the shared controls that the toolbar, menus, and a ribbon would all reuse.

Paste  — the primary action. Clicking the label runs the most-common variant (Keep Source Formatting) with no menu, the same as pressing ^V.
▾  — the dropdown zone. A separate hit target that opens the full menu of paste variants without triggering a paste.
The split exists precisely because the action and its options differ: you usually want one default paste, but occasionally need to choose. The checked row (Keep Source Formatting) is what the left zone does, so the menu also tells you what the button is.
A concrete split button. The left zone carries a named primary action — Paste, equivalent to ^V — and clicking it pastes immediately. The ▾ zone is a distinct hit target that opens the Paste Special menu: Keep Source Formatting (the current default, ticked), Merge Formatting, Values Only, Plain Text, and the fuller Paste Special… options, each with its accelerator. Critically, the ticked menu row is what the left zone does — so the menu both offers alternatives and documents the button’s current behaviour. That dual role is the whole reason to use a split button instead of a plain button + separate menu.
