The tag input holds committed values as chips (icon + label + ✕ remove) with a live text caret after the last chip. Typing filters a completion dropdown with match-highlighting, usage counts, fuzzy hits, and a "Create" row for new tags; Enter/Tab/comma commit. Validation states read through whole-cell fills, not outlines: a re-entered value flags as a duplicate (red-tinted chip), hitting the cap switches the field to an amber fill and disables input, Backspace on an empty caret selects the last chip (accent fill) for deletion, the focused field brightens its well, and a disabled control greys its chips.

▸ Masked text inputs

Masked inputs render the mask template inline: literal characters (parentheses, slashes, dots, spaces) are fixed, fillable positions show as slot placeholders (underscores or letter hints) until typed, and entered characters land left-to-right with the caret at the next open slot. A failed format/checksum (here a card failing Luhn) tints the field red.

▸ Part editors — spinnable date / time segments

Date2026-06-13▲▼year segment selected · ↑↓ spins just that part · ←→ moves between parts
Time09:30:00AM▲▼minute segment selected · AM/PM toggles with ↑↓ when focused
Duration02h45m30s▲▼unit-labelled parts (h/m/s) · overflow carries into the next part
Part editors split a structured value into independently-focusable segments. Exactly one part is selected (accent fill); ↑↓ spins only that part (with carry/overflow into neighbours), ←→ or typing the separator moves between parts, and direct digit entry overwrites the focused segment. The shared ▲▼ spinner acts on whichever part holds focus — so a date, clock time, and an h/m/s duration all use the same interaction.

The numeric editor scrubs by dragging its ⋮⋮ grip horizontally (modifier keys change the step), with a spinner fallback. The rating supports half-steps (⯨) and previews the hovered value in cyan ahead of the committed amber stars. The slider carries a labelled tick scale beneath the filled track, the thumb a single cell on the rail.
