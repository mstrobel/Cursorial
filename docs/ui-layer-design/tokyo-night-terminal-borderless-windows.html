tokyo-night — borderless windows — 110×40
Borderless, fill + padding: windows separate from the desktop by tonal elevation (desktop → body → raised → highest), not drawn borders. Interior padding keeps content off the invisible edge; a filled title band, a raised footer, and an optional whole-cell shadow imply depth. Everything stays cell-aligned — the “border” is just where one fill meets another.

▸ Elevation ramp — the surfaces that replace borders

Depth comes from a deliberate fill ramp. Each surface is one step lighter (dark theme) than the one it sits on, so an edge reads as a tonal seam rather than a line. The desktop is darkest; the window body lifts off it; title bars, footers, and buttons use the raised/highest steps; inputs recess to the well. Four steps is enough to layer a full UI without a single border glyph.

Three depths from the same parts. Flat relies only on the body-vs-desktop tonal seam — cleanest, good for tiled/full-pane layouts. Raised adds a whole-cell shadow (a darker fill offset down-right, not a blur) for floating windows. Inactive windows drop the accent title band and any shadow, sitting flat so the focused window stands out. Active windows carry the accent title bar; inactive ones the grey raised band.

A master–detail settings window, fully borderless: the sidebar is the raised fill, the detail pane the window fill, and the seam between them is the only thing dividing the two panes — no rule. Selected nav item gets the accent fill. Controls (segmented Dark/Light/Auto, well-filled dropdowns, an on/off switch) are all flat fills with padding. A raised footer band holds the actions, default in accent.

Toasts are tiny borderless windows — each a card with a status glyph, a title + detail, and either a dismiss ✕ or inline actions. They stack with the whole-cell shadow so they float above whatever's behind. No title bar needed; the card fill and shadow alone separate them from the desktop. Severity reads from the leading glyph colour (✓/⚠/ⓘ).
